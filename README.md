# Supplier ERP Platform - KSA Compliant

**Live Demo:  https://supplier-platform-beta.vercel.app/dashboard/
### Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Supabase, Prisma ORM, PostgreSQL
- ERP Logic: Inventory Module, PO Workflow, VAT Engine
- Compliance: ZATCA E-Invoicing Integration, QRCODE
- DevOps: Docker, Vercel


### Overview
A complete ERP solution for suppliers and distributors in KSA. It digitizes the entire supply chain from purchase orders to delivery and invoicing, built for the Saudi market.

### Aim
To build a ZATCA-compliant ERP that helps Saudi SMEs manage suppliers, inventory, and VAT invoicing in one place without needing expensive software like SAP.

### Key Features
- **Supplier & Buyer Management:** Onboarding, credit limits, and performance tracking
- **Inventory & PO System:** Real-time stock, purchase orders, and delivery status
- **ZATCA Compliant E-Invoicing:** VAT calculation and e-invoice generation as per KSA regulations
- **Dashboard & Risk Alerts:** Low-stock alerts, payment delays, and supplier risk scoring
